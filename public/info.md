# ConClár Summit Demo

## Note about programme data

This is a demo schedule generated using [Drupal Summit Site
Template](https://www.drupal.org/project/summit), which is built on the [Event
Platform](https://www.drupal.org/project/event_platform) recipe, and exported
using the [Event Platform
ConClár](https://www.drupal.org/project/event_platform_conclar) module.

This demo is hosted on GitHub pages.


## About ConClár

ConClár is an open source browser based convention programme guide created by
[James Shields](https://drupal.org/u/lostcarpark). For more
information, visit the [project page](https://github.com/lostcarpark/conclar).
